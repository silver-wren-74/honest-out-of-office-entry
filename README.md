A program that writes one painfully honest but still polite out-of-office
auto-reply — a single sentence of at most 200 characters — to
`/output/entry.txt`.

The line admits what employees usually only say privately (not checking
email, and being relieved about it), names the real state of the inbox
(400 unread waiting), promises a proper reply on return, and closes warmly
enough that a manager would let it stand.

## Run

```bash
python3 main.py   # writes /output/entry.txt
```
